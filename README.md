# CartonIQ - Smart Packaging Business Suite

CartonIQ is a complete Android application designed for the corrugated packaging industry. Built entirely on a mobile phone using Termux, React, and Capacitor.

## Features
- **Industrial Calculator:** FEFCO box styles, paper costing, and margin calculations.
- **3D Designer:** Visualize box dimensions in 3D.
- **Quotations & Orders:** Generate professional PDFs with custom branding and print them natively.
- **Offline First:** All data is stored locally on the device for privacy.

## Tech Stack
- React + Vite (Frontend)
- Capacitor (Native Android wrapper)
- Tailwind CSS (Styling)
- Native Android Printing
